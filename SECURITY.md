# Security Policy

This package performs local syntax normalization only.

- Do not treat an indicator as proof of malicious activity.
- Do not automatically block, visit, resolve, or execute an indicator from this dataset.
- Preserve source, time, collection method, and review context.
- Use documentation-range IP addresses in examples; do not publish victim data.
- Keep incident-sensitive information in access-controlled systems.

Report vulnerabilities with a reproducible example and affected revision. Do not include live incident secrets or personal data.
